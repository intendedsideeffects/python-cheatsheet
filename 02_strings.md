# Strings

```python
text = "Python is fun"
```

## Access and slice
```python
text[0]       # 'P'
text[-1]      # 'n'
text[0:6]     # 'Python'
```

## Useful operations
```python
len(text)
text.lower()
text.upper()
text.strip()
text.replace("fun", "useful")
text.split(" ")
"Python" in text
```

## f-strings
```python
name = "Janina"
score = 95
message = f"{name} scored {score}%"
```
