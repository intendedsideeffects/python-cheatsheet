# Conditions

```python
score = 82

if score >= 90:
    print("Excellent")
elif score >= 70:
    print("Good")
else:
    print("Keep practicing")
```

## Comparison operators
```python
==   # equal
!=   # not equal
>    # greater than
<    # less than
>=   # greater than or equal
<=   # less than or equal
```

## Logical operators
```python
and
or
not
```

Example:
```python
if age >= 18 and has_ticket:
    print("Enter")
```
